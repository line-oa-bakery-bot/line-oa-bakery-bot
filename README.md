# บอทจดออเดอร์ขนม (LINE OA นพวรรณเบเกอรี่)

บอทนี้ทำ 4 อย่าง:
1. เมื่อมีคนพิมพ์ข้อความขึ้นต้นด้วย **"ออเดอร์"** ในกลุ่มไลน์ → เก็บข้อความเดิมไว้ทั้งหมด ไม่แก้ไขเนื้อหา
2. แยกแยะ "วันที่" จากข้อความให้อัตโนมัติ รองรับ:
   - คำสัมพัทธ์: `วันนี้`, `พรุ่งนี้`, `มะรืนนี้`
   - วันที่ตัวเลข: `20/9`, `20/9/2569`
   - วันที่ + ชื่อเดือนไทย: `20 กันยายน`, `20 ก.ย.`
3. ทุกวันเวลา **8:00 น. (เวลาไทย)** จะส่งข้อความสรุปเข้ากลุ่มอัตโนมัติว่าวันนั้นมีออเดอร์อะไรบ้าง (ถ้าไม่มีก็จะแจ้งว่าไม่มี)
4. **ถามได้ทุกเวลา** ว่าวันไหนมีออเดอร์อะไรบ้าง โดยไม่ต้องรอถึง 8 โมงเช้า เช่น
   - `พรุ่งนี้มีออเดอร์อะไรไหม`
   - `วันที่ 13 มีงานอะไรบ้าง`
   - `มะรืนนี้มีออเดอร์ไหม`
   - `เช็คออเดอร์วันนี้`

   บอทจะตอบกลับสรุปออเดอร์ของวันนั้นทันที (เงื่อนไข: ข้อความต้องมีคำว่า "ออเดอร์" หรือ "งาน" ร่วมกับคำถามอย่าง "อะไร/บ้าง/ไหม/เช็ค" และห้ามขึ้นต้นด้วยคำว่า "ออเดอร์" มิเช่นนั้นจะถูกตีความเป็นการบันทึกออเดอร์ใหม่แทน)

---

## ขั้นตอนที่ 1: ไปเอา Channel Access Token และ Channel Secret

1. เข้า https://developers.line.biz/console/ แล้ว login ด้วยบัญชีเดียวกับที่ผูก LINE OA นพวรรณเบเกอรี่ไว้
2. เลือก Provider ของร้าน แล้วเลือกช่อง (Channel) ที่เป็น **Messaging API** ของ OA นี้
   - ถ้ายังไม่มี Messaging API channel: ไปที่ **LINE Official Account Manager** (https://manager.line.biz) → เลือก OA ร้าน → **Settings > Messaging API** → กด "Enable Messaging API" แล้วมันจะสร้าง channel ให้อัตโนมัติ และไปโผล่ที่ Developers Console
3. ในหน้า Channel:
   - แท็บ **Basic settings** → คัดลอกค่า **Channel secret**
   - แท็บ **Messaging API** → เลื่อนลงไปหา **Channel access token** → กด "Issue" เพื่อออก token (แบบ long-lived) → คัดลอกเก็บไว้
4. ในหน้าเดียวกัน (Messaging API tab) เลื่อนหา **"Allow bot to join group chats"** → เปิดให้เป็น ON (ไม่งั้นชวนบอทเข้ากลุ่มไม่ได้)
5. ปิด **"Auto-reply messages"** และ **"Greeting messages"** ที่ LINE Official Account Manager > Settings > Response settings เพื่อไม่ให้ข้อความอัตโนมัติของ LINE มากวนกับบอทของเรา

เก็บค่า 2 ตัวนี้ไว้ก่อน:
- `CHANNEL_ACCESS_TOKEN`
- `CHANNEL_SECRET`

---

## ขั้นตอนที่ 2: Deploy โค้ดขึ้น hosting ฟรี (แนะนำ Railway)

**Railway** ใช้ง่ายและมี free tier พอสำหรับงานขนาดนี้

1. สร้างบัญชี GitHub (ถ้ายังไม่มี) แล้วสร้าง repo ใหม่ อัปโหลดโค้ดทั้งหมดในโฟลเดอร์นี้ขึ้นไป
2. เข้า https://railway.app → สมัคร/login ด้วย GitHub
3. กด **New Project → Deploy from GitHub repo** → เลือก repo ที่เพิ่งสร้าง
4. ไปที่แท็บ **Variables** ของ project แล้วเพิ่ม:
   - `CHANNEL_ACCESS_TOKEN` = (ค่าที่ได้จากขั้นตอนที่ 1)
   - `CHANNEL_SECRET` = (ค่าที่ได้จากขั้นตอนที่ 1)
   - `GROUP_ID` = (ข้ามไปก่อน ยังไม่รู้ค่า จะกลับมาใส่ในขั้นตอนที่ 4)
5. ไปที่แท็บ **Settings → Networking** กด **Generate Domain** จะได้ URL ประมาณ
   `https://line-oa-bakery-bot-production.up.railway.app`
6. Railway จะ build และรันให้อัตโนมัติ (รอสัก 1-2 นาที)

> ทางเลือกอื่นที่ใช้ได้เหมือนกัน: **Render.com** (ฟรีเช่นกัน แต่ฟรีทำให้ server sleep ถ้าไม่มีคนเรียกนานๆ ซึ่งอาจกระทบ webhook — ถ้าจะใช้ Render แนะนำอัปเป็น paid tier เล็กๆ เพื่อให้ server ไม่หลับ)

---

## ขั้นตอนที่ 3: ตั้งค่า Webhook ใน LINE Developers Console

1. กลับไปที่ Developers Console → Channel ของ OA → แท็บ **Messaging API**
2. ช่อง **Webhook URL** ใส่: `https://<โดเมนที่ได้จาก Railway>/webhook`
   เช่น `https://line-oa-bakery-bot-production.up.railway.app/webhook`
3. กด **Verify** ให้ขึ้นว่าสำเร็จ
4. เปิด **Use webhook** เป็น ON

---

## ขั้นตอนที่ 4: ชวนบอทเข้ากลุ่ม แล้วหา Group ID

1. เพิ่ม LINE OA นพวรรณเบเกอรี่เป็นเพื่อน (ถ้ายังไม่ได้เพิ่ม) แล้วชวนเข้ากลุ่มไลน์ที่มีแม่อยู่
2. ให้ใครก็ได้ในกลุ่มพิมพ์อะไรก็ได้ 1 ข้อความ (เช่น "สวัสดี")
3. ไปที่ Railway → project → แท็บ **Deployments** → เปิด **Logs** → จะเห็นบรรทัด
   `Group ID: Cxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   คัดลอกค่านี้ (ขึ้นต้นด้วย C ตามด้วยตัวอักษร/ตัวเลข)
4. กลับไปที่ Railway → **Variables** → แก้ `GROUP_ID` ให้เป็นค่านี้ → บันทึก (Railway จะ redeploy ให้อัตโนมัติ)

---

## ขั้นตอนที่ 5: ทดสอบ

พิมพ์ในกลุ่ม:
```
ออเดอร์ เค้กช็อคโกแลต พรุ่งนี้
```
บอทควรตอบกลับว่า "บันทึกออเดอร์แล้วค่ะ ✅ (วันที่ .../.../...)"

พิมพ์ทดสอบดูสรุปได้ทันที (ถามได้ตลอดเวลา ไม่ต้องรอ 8 โมง):
```
เช็คออเดอร์วันนี้
พรุ่งนี้มีออเดอร์อะไรไหม
วันที่ 20 มีงานอะไรบ้าง
```

พอถึง 8:00 น. ของวันนั้น บอทจะส่งสรุปเข้ากลุ่มให้อัตโนมัติ

## หมายเหตุ

- ข้อมูลออเดอร์เก็บไว้ที่ไฟล์ `data/orders.json` บน server — ถ้าจะใช้งานจริงระยะยาวและออเดอร์เยอะมาก ค่อยพิจารณาย้ายไปใช้ฐานข้อมูลจริง (เช่น Railway มี PostgreSQL ให้เพิ่มได้ฟรีในโปรเจกต์เดียวกัน)
- ถ้าต้องการลบออเดอร์ของวันไหนออก (เช่น หลังทำเสร็จแล้ว) แจ้งได้ เดี๋ยวเพิ่มคำสั่งลบให้
- ถ้าอยากให้แจ้งเตือนล่วงหน้า 1 วัน (เช่น เตือนตอนเย็นว่าพรุ่งนี้มีอะไรบ้าง) ก็เพิ่ม cron อีกอันได้เช่นกัน
